LALAY.STUDIO — Responsive, installable portfolio website

INCLUDED
- index.html: portfolio content, mobile menu, and category sliders
- style.css: dark cinematic styling for phone, tablet, laptop, and desktop
- manifest.webmanifest + icon.svg: installable web app metadata/icon
- service-worker.js: caches the app shell for basic offline access after first load

RUN LOCALLY
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Run index.html with Live Server (recommended).
   PWA installation/service worker requires HTTPS or localhost; opening file:// directly
   will not enable installation/offline caching.

MOBILE + DESKTOP
- Responsive layout and touch-friendly mobile navigation.
- Portfolio categories support horizontal swiping.
- Videos use native HTML controls and playsinline where included.
- To install on a phone, deploy to HTTPS and choose "Add to Home Screen" or "Install app"
  in a supported browser.

MEDIA
The showcase uses online sample images. Replace sample image URLs and video/image paths
with your own project files before publishing. Personal video assets are not included.

BEFORE PUBLISHING
Replace placeholder email and social links in index.html with your real contact details.
